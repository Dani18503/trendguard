# 🔐 TrendGuard - Manual de Administrador

Este documento es para el CEO (tú). Contiene las instrucciones para gestionar clientes y licencias.

## 🎯 Generar una Licencia
1. Entra al panel de administración: http://63.177.89.167:8502
2. Inicia sesión con tus credenciales.
3. Rellena el formulario:
   - Nombre del cliente
   - Días de vigencia
   - Activos permitidos
4. Haz clic en "Generar Licencia".
5. Descarga el archivo .lic generado y envíalo al cliente.

## 📋 Historial de Licencias
En la pestaña "Historial" puedes ver todas las licencias generadas, con fechas de vencimiento y activos.

## 🚫 Revocar una Licencia
Actualmente, para revocar una licencia, debes esperar a que expire. En el futuro se implementará revocación online.
